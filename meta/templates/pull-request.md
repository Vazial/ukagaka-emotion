# PR雛形（実体は `.github/pull_request_template.md`）

PR本文の雛形は **`.github/pull_request_template.md` が実体**である。GitHubがPR作成時に自動で開く
ファイルであり、全PRが必ず通る関所だからである（`meta/adr/0057` 決定3）。ここには複製を置かない
——同じものを2箇所に置けば必ず食い違う（P-04）。実際に、複製を置いていた間に食い違っていた。

書き方の規則は `meta/adr/0057`。要点は、区切り線より上を**このリポジトリを知らない人が読んで
分かるように書く**ことである。

- 上段: 何が変わるか ／ 判断してほしいこと ／ なぜ ／ 代償・残る弱点
- 下段（記録）: 変更したファイル ／ 検証 ／ 統合先と対象契約 ／ 手続き ／ 備考
