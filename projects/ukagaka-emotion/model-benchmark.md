# 埋め込み方式の実測結果（第1段）

第1段では外部APIを使わず、Python標準ライブラリだけで動く日本語文字特徴の小型ローカル方式を比較した。
同じ18件（9分類×見本2件）を同じ分類核で評価した実測結果を記録する。測定環境は Python 3.14.0、単一プロセス、ウォームアップなしである。

| 方式 | 特徴 | 正解率 | 1件あたり応答時間 |
|---|---|---:|---:|
| char-unigram | Unicode文字の単語なし特徴 | 1.0000 | 0.117 ms |
| char-ngram | 2〜3文字の日本語特徴 | 1.0000 | 0.196 ms |
| char-hybrid | 文字＋2〜3文字特徴 | 1.0000 | 0.265 ms |

採用方式は `char-hybrid` とする。日本語の分かち書き器を依存せず、単文字で未知語にも対応しつつ、複数文字のまとまりで典型表現を拾えるためである。最終的な精度・速度の合格基準は契約どおり設けない。
